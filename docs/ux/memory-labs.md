# Memory and Labs: screen specs

Status: Draft v0.2 (revision 1), 29 Oct 2026. One block per screen for every **MEM** and **LAB** screen. Logic, branches, data and events are in `docs/flows/memory-labs.md` (cited below as "flow §n"). Components and tokens are from `DESIGN.md` §2–§5 and §7; values live in `packages/tokens/tokens.json`.

- Placeholders in `{braces}` are study content or data, produced by skills, never written here (AGENTS.md rule 1). UI copy (buttons, pet lines, empty states, safety rules) is written here in English and Hindi.
- `{pet_name}` is the student's pet's name. Pet lines are the same for cat and dog unless noted.
- Every illustration slot is generated by Agnes through `skills/visual-director` (AGENTS.md rule 2). Slots name a preset from DESIGN §6.2. Icons are Phosphor (DESIGN §5).
- "Subject colour" means the subject family of the item, through `subjectMap`.
- Hindi copy uses आप everywhere (R3). Little-learner (class 1–5) variants use तुम and are marked `_ll` (P7). Pet lines avoid gendered verb forms.
- A screen's phase is in its Purpose line when it is not Phase 1 (R8). Little-learner states are Phase 3 everywhere.

## 0. Shared patterns

These recur on many screens. Screens below refer to them by name.

**P1 · Rating row.** Four Rating buttons (DESIGN §5) in one row, each 56 tall, 12 px gaps, radius `button`. Each shows an icon, a label and the next interval in `caption` with tabular figures. Fills use tints so the `*Text` contrast pairs hold:

| Button | Fill | Text and icon | Icon |
|---|---|---|---|
| Again | `errorTint` | `errorText` | `ArrowCounterClockwise` |
| Hard | `warningTint` | `warningText` | `Barbell` |
| Good | `successTint` | `successText` | `Check` |
| Easy | `primaryTint` | `primary` | `Lightning` |

At 200% dynamic type the row becomes a 2 × 2 grid. Hindi labels fit at the same width (checked: "फिर से", "कठिन", "ठीक", "आसान").

**P2 · Pro chip.** A status Chip on `primaryTint` with `primary` text, Phosphor `LockSimple` at 16 px plus the word "Pro" / "प्रो" (the same chip as learn's screens). Never gold: gold is only for the streak, plant, gems and the ₹1 tag (R11). Never colour alone: the word is always there. Tapping anything carrying it opens PAY-01 Paywall with a `source`, and for little learners PAY-03 Grown-up check first, with no price shown (R14). Never shown inside MEM-03, MEM-04 or MEM-32 (R15).

**P3 · Offline banner.** The slim banner from UX_FLOW §4.3 ("Offline. Downloaded lessons still work.") on `surfaceSunken`, `inkMuted` text, `WifiSlash` icon. Memory screens change the copy to "Offline. Your reviews still work."

**P4 · Heavy surface top bar** (LAB-04, LAB-08, LAB-10). 56 tall on `surface` (`bg` in full screen), [✕] close (48 × 48), title in `heading` (one line, truncates with an ellipsis only at word ends; the full title is in the accessibility label), an [ⓘ] info button (opens LAB-18) and a `DotsThreeVertical` overflow. In full-screen landscape it auto-hides after 3 s of no touches and returns on tap (not in reduced motion: then it stays).

**P5 · Pet line.** DESIGN §5 Pet line: 40 px pet avatar (Rive, static pose in reduced motion) and a speech bubble on `surface`, at most 2 lines.

**P6 · Placeholder media tile.** While an image is loading or being generated: a tile in the subject tint, the same ratio as the final image, with a gentle `fast` opacity pulse (no pulse in reduced motion) and the alt text as its accessibility label.

**P7 · Little-learner copy.** Keys ending `_ll` are the class 1–5 variant (Phase 3). Only these use तुम (R3). Example: `got_it_ll` "Got it!" / "आ गया!".

**P8 · First-time pet demo.** The first time a card type or mode appears (flow §5.15), the pet runs two or three coach-mark bubbles over a sample card, at most 10 seconds, with [Skip]. A `Question` icon button (48 × 48, label "How this works" / "यह कैसे काम करता है") in the top bar replays it. Reduced motion: static bubbles. Copy keys `demo_{feature}_{step}`; texts are UI copy written with the screen.

**P9 · Streak chip.** A compact Chip on `streakTint` with `streakText` and Phosphor `Plant` (fill) 16 px (R28), shown until today is a streak day: "{n} more reviews to keep your streak" / "स्ट्रीक के लिए {n} और रिव्यू". `{n}` is `streak.reviews_to_qualify` minus today's reviews (flow §5.1). At 0 it becomes "Streak kept ✓" / "स्ट्रीक बनी रही ✓" for 3 s, then hides. Hidden when today already qualifies from a lesson, mock section or the daily challenge. Accessibility: read as a status ("4 more reviews to keep your streak"), announced politely once at 0.

## MEM · Memory

### MEM-01 · Memory hub
**Purpose:** one place for every memory tool, led by today's reviews. **Main action:** [Start review].
**Entry → exits:** HOME-01 (Memory row "See all"), ME-01 (My memory row), HOME-05 search, MEM-23 → MEM-03 (also rescue mode), MEM-02, MEM-07, MEM-12, MEM-19, MEM-22, MEM-24, MEM-25, MEM-28, MEM-06.
**Layout (top to bottom):**
1. Header: back button, title "Memory" in `title`, settings icon `GearSix` (opens MEM-06).
2. **Today card** (hero, radius `cardLarge`, `primaryTint`): illustration right, "{n} cards today · {m} min" in `heading` with tabular figures, a one-line state ("Due now", "All caught up", or "Comeback day 2 of 3"), Progress bar for cards done today, primary Button [Start review] (56, full width inside the card). When a comeback plan is active the card shows the plan line and [Continue plan].
3. **Streak line** under the card: the P9 streak chip, or "Streak kept ✓" when today already qualifies.
4. **Tools grid** (2 columns, 12 px gaps, cards radius `card`, `surface` with card shadow): Decks · Memory palace (P2 chip for free) · Make it stick (P2 chip for free) · Audio hooks (P2 chip for free) · Techniques · How well I know it (metacognitive) · Focus timer. Each card: `sunny-object` illustration top-right, name in `label`, one meta line in `caption` ("6 decks", "2 palaces", "25 min").
5. **Weak-area strip** (only when the server sent an alert): "You'll forget {topic_title} soon. {k} cards." with [Review now] ghost button.
6. Tab bar (Learn tab active, because Memory is not a tab and the hub opens over Learn, R17).

**Illustration slots:**
- Today card: `sunny-object`, 1:1, a stack of friendly flashcards with a small spark, decorative (the text carries meaning). When nothing is due: `empty-state`, 4:3, the pet relaxing on a cushion beside a neat card stack; alt "Your pet relaxing, all reviews done".
- Tool cards: `sunny-object`, 1:1, one object each: card stack (decks), a small palace or house with doors (palace), a glowing knot or pin (make it stick), headphones with a music note (audio), an open book with a lightbulb (techniques), a mirror or a gauge (metacognitive), a tomato-shaped timer with the pet's paw (focus). Decorative, the label names the tool.

**States:**
- Default: as above.
- Nothing due: Today card shows the `empty-state` art, "All caught up", Pet line with the next review time, and [Practise a deck] secondary instead of the primary button.
- Comeback active: Today card in `streakTint` with plant avatar and "Comeback day {d} of {total}".
- Plant thirsty or droopy and today not yet a streak day (flow §5.13): the Today card adds a ghost [2-minute rescue] under [Start review].
- Loading: cards render instantly from the local DB; only the weak-area strip waits for the network, and it simply doesn't appear if offline.
- Offline: P3 banner (memory copy). Everything except the weak-area strip works.
- Guest: same as signed in. Pro tools show P2.
- Free vs Pro: P2 chips on Memory palace, Make it stick and Audio hooks.
- Little learner (Phase 3): a simpler hub reached from HOME-06: Today card ("Picture cards"), Audio rhymes, and nothing else. Larger cards (one column). No P2 chips and no prices.
- Dark mode: Today card on `primaryTint` dark; tool cards on `surface`, no shadows.

**Interaction and motion:** card press scale 0.97 (`fast`). Today card progress fills with spring `gentle` when returning from a session. Pull to refresh (pet peeks) refreshes the weak-area alert. Haptic light on taps.
**Accessibility:** focus order: back, settings, Today card (one group: "{n} cards today, about {m} minutes. Start review, button"), tools in reading order. P2 chips read "Pro feature". Tool cards are buttons with their names. Dynamic type: grid becomes one column at 150%.
**Analytics:** `screen_view {screen: mem_hub}`, `review_session_started` (from the button), tool taps as `memory_tool_opened {tool}`.
**Web (≥ 600 px):** two-pane: Today card and weak-area strip in a left column (360 px), tools grid in 3 columns on the right. Sidebar navigation replaces the tab bar (UX_FLOW §4.17).
**Mock priority:** P0.

**Entry → exits:** HOME-01 Review row, NTF-07 Welcome back (30+ days away), MEM-01, `smriti.app/review` when the backlog rule fires (flow §5.2) → MEM-03 (today's chunk), LRN-07 Quick revision sheet (relearn topics), MEM-03 normal ("Just review normally"), back to HOME-01.
**Layout (top to bottom):**
1. Top bar: [✕] close only.
2. Hero illustration (40% height): the pet and the plant together, the plant in its current health state.
3. Title in `title`: "Welcome back, {first_name}!" (guest: "Welcome back!").
4. Body in `body`, `inkMuted`: "{total} cards waited for you. No rush. Let's spread them out."
5. **Plan picker:** a segmented control on `surfaceSunken` with 3 days · 5 days · 7 days; the recommended one has a small "Suggested" caption under it. Below it a Stat tile row: "{k} cards a day" and "about {m} min a day" (tabular figures).
6. **Relearn card** (only when low-recall cards exist): `surface` card with `BookOpen` icon: "{r} cards are very faded. Quick Revision of {t} topics is faster than flipping them." with a list of up to 3 topic chips in their subject colours and "+{x} more".
7. **Plant line:** Pet line: "Each day you finish waters the plant. {plant_days} days to wake it up."
8. Pinned bottom: primary Button [Start today's {k} cards], ghost Button [Just review normally].

**Illustration slots:** `sunny-scene`, 3:2, the pet gently watering the plant in its pot by a window at morning light; the plant's look follows its health state (the plant itself is the Rive `plant.riv` layered on a scene background, so the health state is live). Alt: "Your pet watering your plant to welcome you back".
**States:**
- Default: as above.
- No history (new student after a long first gap): "Suggested" uses the default seconds per card; minutes say "about".
- No relearn group: the relearn card is hidden.
- After 30+ days away (from NTF-07): the stat row says "Today: {k} cards" for a short first session (`memory.comeback.first_session`), then the plan's normal chunks from tomorrow (flow §5.2).
- Plant thriving (backlog came from many lessons, not absence): the plant line is replaced with "Lots learned! Let's keep it fresh."
- Offline: works fully; the relearn CTA says "Needs download" on topics not downloaded.
- Little learner: never shown; little learners get a 5-card session.
- Dark mode: scene illustration unchanged; segmented control on dark `surfaceSunken`.

### MEM-03 · Review session
**Purpose:** recall one card at a time and rate how well you remembered. **Main action:** rate the card (P1).
**Entry → exits:** MEM-01, MEM-02, MEM-08 (Study now, Free practice), HOME-01 (Review row, streak card rescue link), HOME-06 (little learner), `smriti.app/review` (`set=quick`, `set=rescue`, `set=bedtime`, `topic=`), NTF-01 (`review_due`, `streak_risk`, `weak_area`, `sleep_review`), NTF-08 and NTF-09 widgets, MEM-18 (palace mode), PRC and MOCK toasts [Review now] → MEM-04 (end), MEM-32 (rescue end), MEM-05 (leech, over the card), MEM-31 (overflow), MEM-27 (feeling), MEM-19, AI-02 ("Ask about this card", card back only), back to entry ([✕]).
**Layout (top to bottom):**
1. **Top bar:** [✕] close, segmented Progress bar (8 px) showing cards done of the session, a counter "6 / 20" in `caption` tabular, the P8 "?" demo button, overflow `DotsThreeVertical` (MEM-31).
2. **Context chip row:** subject Chip (tint + `*Text`), deck or topic name in `caption`, and the P9 streak chip at the row's end (it wraps to its own line at large text). In topic mode the header strip uses the subject tint.
3. **Card** (centre, radius `cardLarge`, `surface`, card shadow, min height 55% of the screen): the card face (see card types in flow §5.1). Images keep their ratio and sit above text. Formula in a Formula box. Long text scrolls inside the card.
   - Front: the prompt. At the bottom of the card: [Show answer] secondary Button (56) and, under it, a Confidence row (DESIGN §5) labelled "How sure are you?" with Sure · 50:50 · Guess.
   - Back: the answer below a `line` divider, then chips: "Your hook" (if a mnemonic is attached, opens it), the emotion tag chip if set, "Updated" if the content changed. A small ghost link "Ask about this card" (`ChatCircleDots`) at the card's bottom opens AI-02 with the card as context. There is no floating tutor button on this screen.
4. **Under the card on the back:** P1 Rating row pinned in the bottom third.
5. **Undo:** a small ghost button "Undo" (`ArrowUUpLeft`) appears top-left of the rating row for the last card only.
6. **Pet** appears as a Pet line sliding up at 50% and at milestones (10th review of the day), then hides after 4 s.

**Illustration slots:** card images come from content (`sunny-object`, `sunny-diagram`, `memory-hook`, alt from the content item) or the student's own card (alt: the student's own text, or "Your picture" if none). No decorative art on this screen: the card is the focus.
**States:**
- Front / back: as above. The rating row is hidden on the front (the space shows the confidence row) so nothing can be rated before recall.
- Quick question card: options as Option cards (DESIGN §5); after the answer, Again is auto-applied on wrong (with [I misread it]), and only Hard, Good, Easy show on right.
- List-in-chunks card: back reveals chunk 1; [Next chunk] secondary until all chunks are shown, then the rating row.
- Audio card: a large play button on the front; the audio plays once automatically unless the phone is silent; captions under it.
- Cram mode: header label "Practice · no schedule change"; intervals hidden; two buttons Knew it / Didn't.
- Sleep mode (Pro, Phase 2, adults only, R34): Night Colour regardless of theme (unless the student turned that off), no sounds, header "Sleep review · 5 cards", pet in its sleepy pose.
- Rescue mode (flow §5.13): header `rescue_header`, plant avatar beside the counter, the P9 chip always shown; at the end MEM-32 opens instead of MEM-04.
- First time a card type or mode appears: the P8 demo runs before the first card.
- Topic mode: header strip in the subject tint with the topic name.
- Palace mode: the card front is the room image with one spot glowing (see MEM-18).
- Loading: none in normal use (cards are local). If a card's media isn't cached and the device is online, the image slot shows P6.
- Offline: P3 banner (memory copy) appears for 3 s then hides; cards needing internet are skipped with the `needs_net` toast.
- Leech: after rating, MEM-05 sheet rises over the card (40% height).
- Little learner (Phase 3): picture card fills the width, audio autoplays, two big buttons "Got it!" (`successTint`) and "Not yet" (`warningTint`, not error red, to stay gentle), session of 5, pet narrates. No P9 chip (streak shows on HOME-06).
- Never on this screen: Pro cards, paywall prompts, shop offers (R15, X8).
- Dark mode: card on `surface` dark, no shadow, `surfaceRaised` for chips; rating tints from the dark set.

**Interaction and motion:**
- Tap anywhere on the card or [Show answer] flips it: a 3D-free flip made of a horizontal scale to 0 and back (`base`, easing `standard`), which is cheap on low-end phones. Reduced motion: a cross-fade (`fast`).
- Tapping a confidence chip selects it (chip fill `primaryTint`) and flips after `instant` delay.
- Rating: the card slides out left (`base`) and the next one slides in; haptic light; no sound per card (sounds only at the end) to keep long sessions calm. Again gives a warning haptic, never a shake.
- Swipe gestures are off by default (accidental ratings are costly); MEM-06 can turn on "Swipe to rate" (left Again, right Good).
- Undo: the last card slides back in from the left.
- Hardware keyboard (tablets) and web: Space flips, 1–4 rate, Z undoes, S / F / G set Sure / 50:50 / Guess.
**Accessibility:** the card is one focusable region; the front's prompt is read, then "Show answer, button" and the confidence group. After flipping, focus moves to the answer, then to the rating row; each rating button reads "Good, next review in 3 days". The flip is announced ("Answer shown"). Images use content alt text. Text scales to 200%; long cards scroll within the card, and the rating row stays pinned. Colour is never alone: every rating has an icon and a word.
**Analytics:** `review_session_started`, `review_card_shown`, `review_rated` (learning event), `review_undone`, `review_session_completed {left_early}`. No card text in any event.
**Web (≥ 600 px):** the card is centred at max 640 px wide; the rating row sits directly under the card, not pinned to the window bottom. Keyboard hints show on hover as small `caption` key caps ("1", "2"…). The tutor opens as a right panel.
**Mock priority:** P0.

**Layout (top to bottom):**
1. Celebration illustration (35% height) with the pet; confetti Lottie for `celebrate` only when the session had at least 10 cards.

3. Stat tile row (3 tiles, tabular): Remembered "{x} / {n}", Time "{m} min", Next "{when}" (for example "Tomorrow · 18 cards").

6. Pinned bottom: primary [Done], secondary [Another {n} cards] (only when more are due today and the daily cap allows).
